*FMV-LifeBook X8200* -- модель корпоративных настольных [[id:7b82dbec-e75c-41dc-ab47-185def5e980e][ноутбуков]] линейки X марки [[id:b173be87-25da-4469-8cda-7d0fe6b4e364][FMV-LifeBook]] компании [[id:6d3573f6-82f2-40ec-9d81-4212810cb937][Fujitsu]] для внутреннего рынка Японии. Выпускалась с апреля 2005 г. и пришла на смену модели [[id:5af038e2-1532-4903-8c64-4fad2edaa288][830NA/H]], являясь фактически той же самой моделью.

* Общая спецификация

- Процессор: Intel [[id:4abceb0a-9cec-44ee-a3aa-def9112ba3dd][Mobile Pentium 4 HT]]
- Чипсет: Intel [[id:e64007f8-4600-4ff6-ae37-b192789a5393][852GME]]
- Память:
  - тип: [[id:db3a6db0-2ba5-4fc1-9eb0-cb973c72a581][PC-2700]] [[id:bdd250ba-2357-4059-ba5a-0f11d35d4f20][DDR-333]]
  - расшириние: [[id:700f6cb8-8388-4b20-a53e-06a3f2ac01ba][SO-DIMM]] x 2 до 1024 Мб
  - максимальный объём: 2048 Мб
- Дисплей: 14.1" XGA 1024x768
- HDD: RAID1 (с индексом G3), Ultra ATA/100
- CD-проигрыватель: CD-ROM
- Дисковод FDD
- Сеть: Ethernet 1000BASE-T/100BASE-TX/10-BASE-T
- Слоты расширения: PCMCIA 2 x Type I/II или 1 x Type III
- Внешний интерфейс: [[id:9678b4c3-012a-497d-b353-afd57d7f7780][USB]] 2.0 x 4, COM, LPT, [[id:8ae452fc-0da3-4599-8f8f-5d6c57a5f931][VGA]], PS/2, IrDA
- Операционная система: Windows XP Prof. SP2
- Размеры: 329 x 299 x 44.5 мм
- Вес: 3.9 кг
