*FMV-LifeBook MC2* -- серия ультракомпактных корпоративных [[id:7b82dbec-e75c-41dc-ab47-185def5e980e][ноутбуков]] линейки MC марки [[id:b173be87-25da-4469-8cda-7d0fe6b4e364][FMV-LifeBook]] компании [[id:6d3573f6-82f2-40ec-9d81-4212810cb937][Fujitsu]] для внутреннего рынка Японии.

* Общая спецификация

- Процессор: Intel [[id:359d2c36-dc7d-45ec-970a-a5ce90f183fe][Mobile Celeron]] с ядром [[id:aa99089a-efe9-4c17-91aa-313334a264eb][Coppermine]]
- Чипсет: Intel [[id:74003cec-13de-4cd8-acfa-331f1f08cf0b][440MX]]
- Оперативная память:
  - тип: [[id:97913e30-bd96-47d4-acbe-fd047c1c5135][PC100]]
  - объём: 128 Мб
  - расширение: 1 x [[id:700f6cb8-8388-4b20-a53e-06a3f2ac01ba][SO-DIMM]]
  - максимальный объём: 256 Мб
- Видеокарта: ATI [[id:697e1375-5072-49b6-8c17-e05ba06ea29e][RAGE Mobility-M]], 4 Мб
- Дисплей: 10.4" TFT SVGA 800x600
- Внешний дисплей: SXGA 1280x1024
- HDD: 20 Гб Ultra ATA/33
- Слоты расширения: PCMCIA Type II x 2 или Type III x 1
- Внешний интерфейс: [[id:9678b4c3-012a-497d-b353-afd57d7f7780][USB]] x 2, [[id:8ae452fc-0da3-4599-8f8f-5d6c57a5f931][VGA]], IrDA
- Сеть:
  - Ethernet 100BASE-TX/10BASE-T
  - Модем V.90 56K
- Размеры: 252 x 216 x 21.8 мм
- Вес: 1.29 кг
