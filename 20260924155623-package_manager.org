*Package Manager* -- менеджер пакетов -- программное обеспечение по управлению пакетами программ и библиотек. Выполняет функции установки, обновления и удаления пакетов. Существую менеджеры пакетов предоставляющие функцию по сборке пакетов из исходных текстов. Работает во взаимодействии с каталогом пакетов и архивом пакетов. Может являться неотъемлемой частью [[id:668ea4fd-84dd-4e28-8ed1-77539e6b610d][операционной системы]] или дополнять её.
