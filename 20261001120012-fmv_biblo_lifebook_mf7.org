*FMV-Biblo LifeBook MF7* -- модель линейки [[id:e19af800-ba4c-482e-9705-ce84fee671d6][FMV-Biblo LifeBook MF]] компании [[id:6d3573f6-82f2-40ec-9d81-4212810cb937][Fujitsu]].

* Общая спецификация

- Процессор: Intel [[id:e711ba12-cea4-4eae-9c34-984d09634718][Mobile Pentium III]] или [[id:359d2c36-dc7d-45ec-970a-a5ce90f183fe][Mobile Celeron (Coppermine)]]
- Объём оперативной памяти:
  - 128 Мб
  - максимальный объём 256 Мб
- Тип памяти: SDR SDRAM [[id:97913e30-bd96-47d4-acbe-fd047c1c5135][PC100]]
- Видеокарта: ATI RAGE Mobility-M с видеопамятью 4 Мб
- Дисплей: 12.1" TFT XGA (1024x768)
- Жёсткий диск: 20 Гб Ultra DMA/33
- Разрешение внешнего дисплея: SXGA (1280x1024)
- Проигрыватель компакт-дисков: DVD-ROM (MF7/700), CD-RW, CD-R, CD-ROM
- Слоты PCMCIA: Type-I или Type-II
- Сетевые устройства:
  - Ethernet 100BASE-TX/10BASE-T (у MF7/600W отсутствует)
  - Модем V.90 56K
- Внешние интерфесы: 2 x USB, FireWire S400, VGA
- Операционная система: Microsoft Windows Millenium
- Программное обеспечение: Microsoft Office XP
- Размеры: 288 x 225 x 24.5-30.5
- Вес: 2.0 кг
