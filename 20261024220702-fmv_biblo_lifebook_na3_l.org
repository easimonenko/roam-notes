*FMV-Biblo LifeBook NA3/L* -- серия корпоративных [[id:7b82dbec-e75c-41dc-ab47-185def5e980e][ноутбуков]] линейки [[id:a549cd6a-7346-4ae7-830a-a4117a1a1ea8][NA]] марки [[id:2f6553a9-c192-44dd-b8cb-55f5ca05bec4][FMV-Biblo LifeBook]] компании [[id:6d3573f6-82f2-40ec-9d81-4212810cb937][Fujitsu]] для внутреннего рынка Японии. - Процессор: Intel [[id:f6fc2fe4-f485-4921-b3c5-f2a8f9a16c3a][Mobile Pentium II]]

- Видеокарта: ATI [[id:a6bb0707-cb6f-4e12-860c-ecea97f32072][3D RAGE LT PRO]]

- HDD: Ultra ATA
- CD-проигрыватель: CD-ROM (с индексе C) или отсутствовал (в индексе A)
- Дисковод FDD
- Сеть:
  - Ethernet 100BASE-TX/10BASE-T
- Внешний интерфейс: [[id:9678b4c3-012a-497d-b353-afd57d7f7780][USB]] x 2, [[id:8ae452fc-0da3-4599-8f8f-5d6c57a5f931][VGA]], COM, LPT, [[id:649ca2ab-2c5b-4960-8cd7-436152c7f077][PS/2]], MIDI, IrDA

- Операционная система: Windows 95, 98, NT 4.0
- Размеры: 310 x 261 x 56 мм
- Вес: 3.5 кг
