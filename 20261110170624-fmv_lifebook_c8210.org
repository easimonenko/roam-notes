*FMV-LifeBook C8210* -- второе поколение моделей [[id:7b82dbec-e75c-41dc-ab47-185def5e980e][ноутбуков]] в линейке [[id:5c53c456-83d4-46bf-843f-aab714f42d29][C]] марки [[id:b173be87-25da-4469-8cda-7d0fe6b4e364][FMV-LifeBook]] компании [[id:6d3573f6-82f2-40ec-9d81-4212810cb937][Fujitsu]] для внутреннего рынка Японии. Выпускалось с ноября 2005 г. и пришло на смену поколению [[id:9c715f38-3f66-4dbe-975c-e36630a4f943][FMV-C8200]].

* Общая спецификация

- Процессор: Intel [[id:094550ce-5282-4eaf-8f39-92e28359030e][Pentium M]]
- Чипсет: Intel 910GML
- Память:
  - тип: PC2-3200
  - максимальный объём: 2048 Мб
- Видеокарта: [[id:b72bea55-0946-40f8-bbe8-09d38dd2e666][встроенная]]
- Дисплей: 14.1" XGA 1024x768
- HDD: Ultra ATA/100
- CD-проигрыватель: CD-ROM
- Дисковод FDD
- Сеть: Ethernet 100BASE-TX/10BASE-T
- Внешний интерфейс: [[id:9678b4c3-012a-497d-b353-afd57d7f7780][USB]] 2.0 x 4, [[id:8ae452fc-0da3-4599-8f8f-5d6c57a5f931][VGA]], COM, LPT, [[id:649ca2ab-2c5b-4960-8cd7-436152c7f077][PS/2]], IrDA
- Слоты расширения: PCMCIA 2 x Type I/II или 1 x Type III
- Внешний дисплей: UXGA 1600x1200
- Операционная система: Windows XP Home SP2, XP Prof. SP2
- Размеры: 333 x 285 x 32.6 мм
- Вес: 3.0 кг
