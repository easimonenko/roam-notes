*FMV-Biblo LifeBook NS2* -- серия [[id:7b82dbec-e75c-41dc-ab47-185def5e980e][ноутбуков]] линейки [[id:120f5203-ec67-491b-9955-a520dd422c49][NS]] марки [[id:2f6553a9-c192-44dd-b8cb-55f5ca05bec4][FMV-Biblo LifeBook]] компании [[id:6d3573f6-82f2-40ec-9d81-4212810cb937][Fujitsu]] для внутреннего рынка Японии. Исторически первая серия линейки NS под маркой FMV-Biblo LifeBook. Вышла в октябре 1998 г. В феврале 1999 г. была заменена на серию [[id:7fa81d4a-2c99-46ec-8d63-9c289a445d55][NS3]].

* Общая спецификация

- Процессор: Intel [[id:f6fc2fe4-f485-4921-b3c5-f2a8f9a16c3a][Mobile Pentium II]]
- Чипсет: Intel [[id:993d359c-04b6-4960-9421-0b8f297f5242][440BX]]
- Память:
  - тип: SDRAM ECC
  - максимальный объём: 192 Мб
- Видеокарта: NeoMagic MagicGraph128XD
- Дисплей: 13.3" XGA
- HDD: Ultra ATA
- CD-проигрыватель: отсутствовал
- Дисковод FDD
- Сеть:
  - модем 56K V.90
- Внешний интерфейс: [[id:9678b4c3-012a-497d-b353-afd57d7f7780][USB]] x 2, [[id:8ae452fc-0da3-4599-8f8f-5d6c57a5f931][VGA]], COM, LPT, [[id:649ca2ab-2c5b-4960-8cd7-436152c7f077][PS/2]], IrDA
- Слоты расширения: PCMCIA 1 x Type I/II
- Операционная система: Windows 95, 98, NT 4.0
- Размеры: 303 x 229 x 25 мм
- Вес: 1.98 кг
