*FMV-LifeBook C6210* -- модель [[id:7b82dbec-e75c-41dc-ab47-185def5e980e][ноутбуков]] линейки [[id:5c53c456-83d4-46bf-843f-aab714f42d29][C]] марки [[id:b173be87-25da-4469-8cda-7d0fe6b4e364][FMV-LifeBook]] компании [[id:6d3573f6-82f2-40ec-9d81-4212810cb937][Fujitsu]] для внутреннего рынка Японии. Модель выпускалась с октября 2005 г. и пришла на смену модели [[id:c6f57cef-83f6-4cc6-b824-cc636f73e91f][C6200]]. В апреле 2006 г. была заменена на модель [[id:85d4bab0-ab4e-4ed7-80a6-e334ddb70ae4][C6220]] с другим дизайном и конструкцией.

* Общая спецификация

- Процессор: Intel [[id:8ca59fb2-28e9-4b14-b7d3-e31c4606d86f][Celeron M]] или [[id:094550ce-5282-4eaf-8f39-92e28359030e][Pentium M]]
- Чипсет: ATI [[roam:Radeon Xpress 200M]]
- Память:
  - тип: [[id:db3a6db0-2ba5-4fc1-9eb0-cb973c72a581][PC-2700]] [[id:bdd250ba-2357-4059-ba5a-0f11d35d4f20][DDR-333]]
  - расширение: [[id:700f6cb8-8388-4b20-a53e-06a3f2ac01ba][SO-DIMM]] x 2
  - максимальный объём: 1280 Мб
- Видеокарта: [[id:b72bea55-0946-40f8-bbe8-09d38dd2e666][встроенная]]
- Дисплей: 14.1" XGA или 15.1" XGA 1024x768
- HDD: Ultra ATA/100
- CD-проигрыватель: DVD-ROM + CD-RW
- Дисковод FDD
- Сеть: Ethernet 1000BASE-T/100BASE-TX/10BASE-T
- Внешний интерфейс: [[id:9678b4c3-012a-497d-b353-afd57d7f7780][USB]] x 4, COM, LPT, [[id:8ae452fc-0da3-4599-8f8f-5d6c57a5f931][VGA]], FireWire
- Слоты расширения: PCMCIA 1 x Type I/II, ExpressCard x 1
- Card Reader: SD
- Внешний дисплей: UXGA 1600x1200
- Операционная система: Windows XP Prof. SP2, XP Home SP2
- Размеры: 329 x 286 x 42.6 мм
- Вес: 3.4 кг
