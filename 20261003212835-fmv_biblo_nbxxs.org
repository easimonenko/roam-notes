* Общая спецификация

- Видеокарта: ATI Radeon Xpress 200M
- Дисплей: 14.1" TFT XGA (1024x768)
- Проигрыватель компакт-дисков: DVD-RAM, DVD-RW, CD-RW
- Сетевые устройства:
  - Ethernet 1000BASE-T/100BASE-TX/10BASE-T
  - WiFi a/b/g
  - Модем V.92 56K
- Внешние интерфесы: 5 x USB, FireWire S400, VGA
- Слоты PCMCIA: 1 x Type-I или Type-II
- Слоты ExpressCard x 1
- Дисковод FDD
- Разрешение внешнего дисплея: UXGA (1600x1200)
- Операционная система: Windows XP Home Edition SP2

  - тип памяти: DDR2-533 PC2-4200
- Размеры: 329 x 283 x 40.5
- Вес: 3.6-4.0 кг
