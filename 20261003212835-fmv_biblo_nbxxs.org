*FMV-Biblo NBxxS* -- серия домашних ноутбуков линейки NB марки FMV-Biblo компании [[id:6d3573f6-82f2-40ec-9d81-4212810cb937][Fujitsu]] для внутреннего рынка Японии.

* Общая спецификация

- Процессор: Intel [[id:b9b708f2-008c-4cfb-839f-868b34cb0909][Celeron M (Yonah)]], [[id:a890bb98-3b3d-4e1c-a362-ce36f241ea18][Core Solo]]
- Оперативная память:
  - объём: 512 Мб в одном слоте
  - один слот расширения для [[id:700f6cb8-8388-4b20-a53e-06a3f2ac01ba][SO-DIMM]]
  - тип памяти: DDR2-533 PC2-4200
- Видеокарта: ATI Radeon Xpress 200M
- Дисплей: 14.1" TFT XGA (1024x768)
- Проигрыватель компакт-дисков: DVD-RAM, DVD-RW, CD-RW
- Сетевые устройства:
  - Ethernet 1000BASE-T/100BASE-TX/10BASE-T
  - WiFi a/b/g
  - Модем V.92 56K
- Внешние интерфесы: 5 x USB, FireWire S400, VGA
- Слоты PCMCIA: 1 x Type-I или Type-II
- Слоты ExpressCard x 1
- Дисковод FDD
- Разрешение внешнего дисплея: UXGA (1600x1200)
- Операционная система: Windows XP Home Edition SP2
- Размеры: 329 x 283 x 40.5
- Вес: 3.6-4.0 кг
