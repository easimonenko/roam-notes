*FMV-Biblo MGxxE*  -- серия компактных [[id:7b82dbec-e75c-41dc-ab47-185def5e980e][ноутбуков]] линейки [[id:0831976b-d826-4419-9adf-87f29561092f][MG]] марки [[id:b3ad9890-6f4f-45f3-9719-8767dc462ab3][FMV-Biblo]] компании [[id:6d3573f6-82f2-40ec-9d81-4212810cb937][Fujitsu]] для внутреннего рынка Японии. Выпускалась с сентября 2003 г. и пришла на смену модели [[id:5797c10c-507c-4807-a9f0-e21406b4bb27][MGxxD]]. Включала в себя две модели: с 13.3" и 15.1" дисплеем. Модель с 15.1" дисплеем родственна модели C1110 марки [[id:7a41a232-5c85-4f23-a9d3-03da18120b26][LifeBook]].

* Общая спецификация

- Память:
  - объём: 256 Мб
  - расширение: [[id:700f6cb8-8388-4b20-a53e-06a3f2ac01ba][SO-DIMM]] x 2
- HDD: Ultra ATA/100
- CD-проигрыватель: DVD-ROM + CD-RW или DVD-RAM/RW
- FDD: внешний (опционально)
- Сеть:
  - Ethernet 100BASE-TX/10BASE-T
  - модем V.92 56K
- Внешний интерфейс: [[id:8ae452fc-0da3-4599-8f8f-5d6c57a5f931][VGA]], [[id:9678b4c3-012a-497d-b353-afd57d7f7780][USB]] 2.0 x 2, IrDA, FireWire S400
- Слоты расширения: PCMCIA 1 x Type I/II
- Card Reader: SD
- Внешний дисплей: UXGA 1600x1200
- Операционная система: Windows XP Home SP1a, XP Prof. SP1a

- Процессор: Intel [[id:a06f9adf-37b1-424f-8709-fc407dfa7373][Mobile Celeron]] с ядром [[id:5f24b9fb-220d-4131-92f0-b2b6a94e826e][Tualatin]]

  - северный мост: Intel [[id:a513312d-9c5f-4c44-b236-a8a1baf46aa3][830MG]]
- Дисплей: 13.3" XGA TFT 1024x768
- Размеры: 293 x 236.5 x 29.5
- Вес: 1.7 кг
