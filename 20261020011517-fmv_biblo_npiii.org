*FMV-Biblo NPIII* -- серия потребительских [[id:7b82dbec-e75c-41dc-ab47-185def5e980e][ноутбуков]] линейки NP марки [[id:b3ad9890-6f4f-45f3-9719-8767dc462ab3][FMV-Biblo]] компании [[id:6d3573f6-82f2-40ec-9d81-4212810cb937][Fujitsu]] для внутреннего рынка Японии. В феврале 1998 г. была заменена на модель [[id:9d4c23ba-0e83-45f5-af60-67ab82ea21f9][NPV]], сохранив дизайн и конструкцию.

* Общая спецификация

- Процессор: Intel [[id:e8a54c2a-7f05-4c04-ad12-e4f151544b3c][Pentium MMX]]
- Чипсет: Intel [[id:153f1f1d-74ef-4861-b83a-aaa72a59660f][430TX]]
- Память:
  - максимальный объём: 96 Мб
- Видеокарта: NeoMagic MagicGraph128ZV+
- Дисплей: 12.1" TFT SVGA 800x600
- CD-проигрыватель: CD-ROM (на док-станции)
- Сеть: модем 56K
- Внешний интерфейс: [[id:9678b4c3-012a-497d-b353-afd57d7f7780][USB]] x 2 + 2, [[id:8ae452fc-0da3-4599-8f8f-5d6c57a5f931][VGA]], COM, LPT, [[id:649ca2ab-2c5b-4960-8cd7-436152c7f077][PS/2]], MIDI, IrDA
- Слоты расширения: PCMCIA 2 x Type I/II или 1 x Type III
- Операционная система: Windows 95
- Размеры: 297 x 232 x 31 мм
- Вес: 2.1 кг
