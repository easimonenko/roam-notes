*FMV-Biblo NE12* -- серия домашних [[id:7b82dbec-e75c-41dc-ab47-185def5e980e][ноутбуков]] линейки [[id:9175c352-9503-4ba3-acbc-c7a18dcbf6b4][NE]] марки [[id:b3ad9890-6f4f-45f3-9719-8767dc462ab3][FMV-Biblo]] компании [[id:6d3573f6-82f2-40ec-9d81-4212810cb937][Fujitsu]] для внутреннего рынка Японии. Сменила серию [[id:3d2caec8-2e77-4f45-95cc-fb97e6dae6ed][NE9]], при этом сама стала последней в линейке.

* Общая спецификация

- Процессор: Intel [[id:8f30407a-9dfc-4e15-aa96-49f58d684bab][Mobile Pentium III-M]]
- Чипсет: Intel [[id:a513312d-9c5f-4c44-b236-a8a1baf46aa3][830MG]]
- Оперативная память:
  - тип памяти: [[id:104a11ae-36fb-4c0d-b784-ba80ba8934d8][PC133]]
  - объём: 256 Мб на плате
  - дополнительно: слот [[id:700f6cb8-8388-4b20-a53e-06a3f2ac01ba][SO-DIMM]] до 512 Мб
  - максимальный объём: 768 Мб
- Видеокарта: [[id:b72bea55-0946-40f8-bbe8-09d38dd2e666][встроенная]]
- Дисплей: 14.1" XGA 1024x768
- HDD: Ultra ATA/100
- Проигрыватель компакт-дисков: DVD-ROM, CD-ROM, CD-R, CD-RW
- Дисковод FDD
- Сетевые устройства:
  - Ethernet 100BASE-TX/10BASE-T
  - Модем V.90 56K
  - WiFi b
- Внешние интерфесы: [[id:9678b4c3-012a-497d-b353-afd57d7f7780][USB]] x 4, FireWire S400, [[id:8ae452fc-0da3-4599-8f8f-5d6c57a5f931][VGA]], COM, LPT, PS/2
- Слоты PCMCIA: Type-II x 2 или Type-III
- Разрешение внешнего дисплея: UXGA (1600x1200)
- Операционная система: Microsoft Windows XP Home Edition
- Размеры: 308 x 282 x 36.2
- Вес: 3.2 кг
