*Fmv-Biblo NE9* -- серия домашних [[id:7b82dbec-e75c-41dc-ab47-185def5e980e][ноутбуков]] линейки [[id:9175c352-9503-4ba3-acbc-c7a18dcbf6b4][NE]] марки [[id:b3ad9890-6f4f-45f3-9719-8767dc462ab3][FMV-Biblo]] компании [[id:6d3573f6-82f2-40ec-9d81-4212810cb937][Fujitsu]] для внутреннего рынка Японии. Серия выпускалась с февраля 2002 г.

* Общая спецификация

- Процессор: Intel [[id:8f30407a-9dfc-4e15-aa96-49f58d684bab][Mobile Pentium III-M]] или [[id:a06f9adf-37b1-424f-8709-fc407dfa7373][Mobile Celeron]] с ядром [[id:5f24b9fb-220d-4131-92f0-b2b6a94e826e][Tualatin]]
- Чипсет: Intel 
- Оперативная память:
  - тип памяти: SDR SDRAM [[id:104a11ae-36fb-4c0d-b784-ba80ba8934d8][PC133]]
  - 256 Мб, распаяна на плате
  - один слот расширения для [[id:700f6cb8-8388-4b20-a53e-06a3f2ac01ba][SO-DIMM]] максимум 512 Мб
  - итого максимальный объём: 768 Мб
- Видеокарта: [[id:ae591f16-48c6-4da0-bbd8-a1fb3028a56b][ATI RAGE Mobility-P]] с видеопамятью 8 Мб
- Объём жёсткого диска: 40 Гб
- Тип интерфейса [[id:bdd1a7fe-9b07-4eae-9fd9-feede71d2e5a][HDD]]: Ultra [[id:c10327f4-e8d0-4271-be12-3039e9742c98][ATA]]/100
- Проигрыватель компакт-дисков: DVD-ROM, CD-ROM, CD-R, CD-RW
- Дисковод FDD.
- Сетевые устройства:
  - Ethernet 100BASE-TX/10BASE-T
  - WiFi b
  - Модем V.90 56K
- Дисплей: 14.1" TFT XGA (1024x768) или SXGA+ (1400x1050)
- Разрешение внешнего дисплея: UXGA (1600x1200)
- Внешние интерфесы: 4 x [[id:9678b4c3-012a-497d-b353-afd57d7f7780][USB]], FireWire S400, [[id:8ae452fc-0da3-4599-8f8f-5d6c57a5f931][VGA]], COM, LPT
- Слоты PCMCIA: Type-I и Type-II или Type-III
- Операционная система: Microsoft Windows XP Home Edition
- Программное обеспечение: Microsoft Office XP
- Питание: 16V 3.75A, коннектор с иглой
- Размеры: 308 x 282 x 36.2-44.8
- Вес: 3.2 кг
