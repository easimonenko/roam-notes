*FMV-Biblo NEIX* -- серия премиальных домашних [[id:7b82dbec-e75c-41dc-ab47-185def5e980e][ноутбуков]] линейки [[id:9175c352-9503-4ba3-acbc-c7a18dcbf6b4][NE]] марки [[id:b3ad9890-6f4f-45f3-9719-8767dc462ab3][FMV-Biblo]] компании [[id:6d3573f6-82f2-40ec-9d81-4212810cb937][Fujitsu]] для внутреннего рынка Японии. Выпускалась с февраля 1999 г. и пришла на смену серии NEVIII. Серия родственна LifeBook [[id:b6bca792-77a7-40a2-8ff7-a118f31a1e68][C3]].

* Общая спецификация

- Процессор: Intel [[id:f6fc2fe4-f485-4921-b3c5-f2a8f9a16c3a][Mobile Pentium II]] или [[id:d1f5835c-1cab-4641-b9a8-5ff2f3561619][Mobile Celeron]]
- Чипсет: Intel [[id:c166c17b-66d0-4b1b-88ce-46a3254771b3][440DX]]
- Память:
  - максимальный объём: 128 Мб
- Видеокарта: Trident Cyber 9388-1
- Дисплей: 13.3" TFT XGA 1024x768
- CD-проигрыватель: CD-ROM
- Дисковод FDD
- Сеть: модем 56K
- Слоты расширения: PCMCIA 2 x Type I/II или 1 x Type III
- Внешний интерфейс: [[id:9678b4c3-012a-497d-b353-afd57d7f7780][USB]] x 1, [[id:8ae452fc-0da3-4599-8f8f-5d6c57a5f931][VGA]], COM, LPT, [[id:649ca2ab-2c5b-4960-8cd7-436152c7f077][PS/2]], IrDA
- Операционная система: Windows 98
- Размеры: 312 x 258 x 48 мм
- Вес: 3.2 кг
