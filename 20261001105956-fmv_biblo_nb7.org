*FMV-Biblo NB7* -- модель [[id:7b82dbec-e75c-41dc-ab47-185def5e980e][ноутбука]] потребительского класса марки FMV-Biblo компании [[id:6d3573f6-82f2-40ec-9d81-4212810cb937][Fujitsu]] для внутреннего рынка Японии.

* Общая спецификация

- Процессор: Intel [[id:e711ba12-cea4-4eae-9c34-984d09634718][Mobile Pentium III]] или AMD Duron
- Объём оперативной памяти:
  - 128 Мб, распаяна на плате
  - один слот расширения для [[id:700f6cb8-8388-4b20-a53e-06a3f2ac01ba][SO-DIMM]] максимум 128 Мб с Intel и 256 Мб с AMD
  - итого максимальный объём: 256 Мб или 384 Мб
- Тип памяти: SDR SDRAM [[id:97913e30-bd96-47d4-acbe-fd047c1c5135][PC100]]
- [[id:221836c2-47cc-4b7d-9287-7c63c41b8d1f][Видеокарта]]:
  - ATI RAGE Mobility-P с видеопамятью 8 Мб (с процессором Intel)
  - ATI RAGE Mobility-EC AGP с видеопамятью 4 Мб (с процессором AMD)
- Дисплей: 14.1" TFT XGA (1024x768)
- Объём жёсткого диска:
  - 20 Гб Ultra DMA/33 (с процессором Intel)
  - 20 Гб Ultra DMA/66 (с процессором AMD)
- Разрешение внешнего дисплея: UXGA (1600x1200)
- Проигрыватель компакт-дисков: CD-RW, CD-R, CD-ROM
- Дисковод FDD.
- Слоты PCMCIA: два Type-I или Type-II, или один Type-III
- Сетевые устройства:
  - Ethernet 100BASE-TX/10BASE-T
  - Модем V.90 56K
- Внешние интерфесы: 4 x USB, FireWire S400, VGA, LPT
- Операционная система: Microsoft Windows Millenium или Windows 2000 Professional
- Программное обеспечение: Microsoft Office XP
- Размеры: 308 x 268 x 36.2-44.8
- Вес: 3.2 кг
